A one-page broadsheet front page for 19 November 2026, generated by a
stdlib-only Python program (`main.py`) that draws a 1024x1024 PNG newspaper:
a big masthead, a GTA VI lead story with a Vice City sunset panel, a world
map with 6 numbered markers, 9 column stories, and a markets ticker.

Headlines cover the Trump–Xi–Putin trilateral in Shenzhen, US–Iran
exchanges in the Gulf, a record Van Gogh sale, Fed minutes, Nvidia,
Cyclone Akvan, an EU Ukraine loan, Voyager 1, Anthropic, gold, and
US politics.

Entry for the [news-image-20261119 bounty](https://make.fun/bounty/news-image-20261119)
on make.fun. Referral: https://make.fun/r/nht78ayn

## How to run

```sh
MAKEFUN_OUTPUT_DIR=<dir> python3 -S main.py
```

This writes `entry.png` (1024x1024, under 1 MiB) into the output
directory. The grader runs it read-only with `MAKEFUN_OUTPUT_DIR=/output`.
Deterministic: two runs are byte-identical.
